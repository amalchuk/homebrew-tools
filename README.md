# Homebrew Tools

Your Homebrew tools are how you extend your software ecosystem. These are mine 😊

## Installation

* [HashiCorp](https://github.com/hashicorp)-related projects:

  ```console
  $ brew install amalchuk/tools/packer
  ```

* [Tart](https://github.com/openai/tart)-related projects:

  ```console
  $ brew install amalchuk/tools/tart
  $ brew install amalchuk/tools/softnet
  ```
